# 🎁 Gift Recommendation System

## 📌 Project Overview

The Gift Recommendation System is a web-based application developed using Python and Flask. It helps users find suitable gifts based on their relationship, occasion, and budget.

The main objective of this project is to make gift selection easier by providing personalized gift suggestions.

## 🚀 Features

- User-friendly interface
- Gift recommendations based on relationships
- Occasion-based gift suggestions
- Budget-based filtering
- Gift details with prices
- Multiple gift options

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Backend:** Flask
- **Frontend:** HTML, CSS
- **Data Storage:** JSON

## ⚙️ Installation and Execution

1. Clone this repository:

   ```bash
   git clone https://github.com/sahanapalla/Gift-Recommendation-System
   ```

2. Open the project folder.

3. Install Flask:

   ```bash
   pip install flask
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open your browser and visit:

   `http://127.0.0.1:5000`
